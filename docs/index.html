Adaptive practice

Learning that adapts

Aprendizaje que se adapta

Performance is tracked independently for each character. Weaker characters receive more attention while consolidated ones continue to be reviewed.

El rendimiento se sigue de forma independiente para cada carácter. Los más débiles reciben más atención mientras los consolidados siguen repasándose.

Practice real reception

Practica recepción real

Listen to Morse, type what you heard and get immediate character-by-character feedback. Sequence length grows progressively as reception improves.

Escucha Morse, escribe lo que has oído y recibe corrección inmediata carácter a carácter. La longitud de las secuencias crece progresivamente al mejorar la recepción.

Usa Audición simplemente para entrenar el oído, también con texto real. El audio en segundo plano permite continuar con la pantalla apagada en configuraciones Android compatibles.

Offline and private

Offline y privado

No account, telemetry, analytics, advertising, cloud services or automatic update checks. Learning data and settings stay on your device.
