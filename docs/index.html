YAMLA

Yet Another Morse Learning App

A simple Android app for learning Morse code reception by sound — progressively, without counting dots and dashes.

Releases GitHub repository

Listen. Recognise. Progress.

Progressive learning

Characters and sequence length are introduced gradually as reception improves.

Learn the sound

Training is designed to encourage direct recognition of each character instead of consciously counting dits and dahs.

Practice and listening

Use interactive practice when you want to answer, or continuous listening when you simply want to train your ear.

Your own pace

Adjust character speed, Farnsworth timing, tone frequency and other listening options.

Offline by design

YAMLA works completely offline. It does not require an account and does not use telemetry, analytics, advertising, cloud services or automatic update checks.

Your learning data and settings stay on your device. YAMLA does not contact GitHub to discover new versions.

Android releases

Official YAMLA builds are published in this repository's Releases section. Each release includes the Android package and its SHA-256 checksum.

Updates are intentionally manual: download a newer official APK and install it over the existing version.

Current scope

  • Morse code reception training
  • Progressive character learning
  • Progressive sequence length
  • Adjustable character speed
  • Farnsworth timing
  • Practice and continuous listening modes
  • Local statistics and learning progress

About this repository

This public repository is used for the presentation and distribution of YAMLA. It does not contain the application's source code.
